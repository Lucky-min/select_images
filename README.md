# select-images

`select-images` 是一个用于解决照片连拍冗余的小工具：它会把短时间内拍摄的照片归为同一组，并从每组里挑出一张更优秀的照片。

## 选择依据

程序会为每张照片计算透明、可解释的质量分：

- **清晰度**：使用亮度拉普拉斯变化评估边缘锐度，优先保留不模糊的照片。
- **曝光**：惩罚过暗、过亮以及高光/阴影严重裁切的照片。
- **对比度**：偏好层次更清楚的照片。
- **饱和度**：偏好色彩适中、不过度灰暗或过饱和的照片。
- **分辨率**：同等情况下保留更高分辨率的照片。

默认权重更重视清晰度和曝光，适合连拍场景中筛掉手抖、失焦、眨眼瞬间附近的冗余照片。

## 安装

```bash
python -m pip install -e .
```

> JPEG、PNG、TIFF、WebP 等常见照片格式需要 Pillow。项目依赖已在 `pyproject.toml` 中声明。

## 使用

扫描一个照片目录，只在终端输出每组最佳照片：

```bash
select-images ./photos
```

将每组最佳照片复制到新目录，并生成 CSV 报告：

```bash
select-images ./photos --output-dir ./selected --report ./selection.csv
```

递归扫描子目录，并把相邻拍摄时间 1.5 秒内的照片视为同一组连拍：

```bash
select-images ./photos --recursive --burst-window 1.5
```

## 分组规则

1. 优先读取 EXIF 拍摄时间。
2. 如果没有 EXIF 时间，则使用文件修改时间。
3. 按时间排序后，相邻照片间隔不超过 `--burst-window` 的会进入同一连拍组。

## 输出说明

终端会显示每组的获胜照片、总分、清晰度、曝光分，以及被淘汰照片数量。CSV 报告会包含每张照片的详细分项，方便人工复核。
